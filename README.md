A passive-aggressive note from a smart fridge to its owner, for the
[make.fun](https://make.fun) bounty
`u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7`.

## The note

> I counted the leftovers you promised to eat. All four are still here, judging you. I taught them.

97 characters, pure ASCII, one line.

## Run

```sh
python3 main.py
```

Writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set).
Python standard library only — no network, no model, no randomness.
